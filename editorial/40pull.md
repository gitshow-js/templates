# One More Argument

<p class="pull">We kept asking how to <em>hold</em> attention. The better question was how to <em>return</em> it.</p>

<p>Restraint is not the absence of design. It is design that has decided what it will not do — and the slow web begins exactly there.</p>

<div class="warning">
Caveat — slow does not mean sparse. A patient page can still be lush; it simply refuses to be greedy.
</div>
