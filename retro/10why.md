# Why Go Retro?

Because constraints are <span class="neon">fun</span>, and the browser is the most accessible canvas ever made:

1. **Zero install** — a `<canvas>` and a URL beat any 1986 floppy
2. **Hard limits breed creativity** — fake the look, learn the math
3. **Instant share** — paste a link, the demo runs everywhere
4. **The aesthetic just rules** — neon, scanlines, grid horizons

<div class="callout">
Every effect tonight runs in a single HTML file. View-source is the whole point.
</div>

- Keep it under <span class="amber">64 kB</span> if you can &ndash; size limits are a love language
- If it doesn't <em>glow</em>, add more glow
- Always ship with chiptune
