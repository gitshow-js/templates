# Why It Hurts

<div class="col">

## The pattern
- Bills arrive *30 days late* and untied to any feature
- Finance and engineering argue over one PDF
- Nobody can answer ``what will we spend next month?''

</div>
<div class="col">

## The cost
- The average mid-market team **overspends 32%** on cloud
- Engineers lose **6+ hours a week** reconciling usage
- A single misconfigured cluster can burn *five figures* overnight

</div>

<div style="clear: both"></div>

<div class="danger">
Cloud is now the <strong>second-largest line item</strong> after payroll — and the only one no one can predict.
</div>

Note:
Anchor every number to a story. The "five figures overnight" line usually lands
with technical investors — ask if anyone in the room has lived it.
